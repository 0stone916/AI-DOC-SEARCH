Current Pain Points

지금 결재 시스템이 해결 못하는 것들

키워드가 달라야만 찾는다

"발주서"를 "구매요청서"로 검색하면 결과 없음. SQL LIKE 검색은 정확한 단어 일치만 가능해 실무에서 매번 단어를 맞춰야 함.

결재선은 매번 수동 설정

문서 종류·금액·부서별로 결재선이 달라지지만 매번 기안자가 직접 선택. 잘못 설정하면 반려·재기안 반복으로 처리 지연.

긴 문서를 처음부터 읽어야

계약서·품의서 검토 시 수십 페이지를 전부 확인해야 핵심 조항 파악 가능. 결재자의 검토 시간이 문서 처리 병목이 됨.
